These documents describe intended direction, not proof that every business unit, service, licence, partnership, account, trader network or platform feature is operational.

The first delivery is a corporate website and lead-generation system. Internal trading operations, external trader services, signal distribution, broker referral workflows and investment capabilities are future workstreams requiring separate specifications, approvals and risk reviews.

## Contributor rules
- Read compliance guidance before implementing financial-services functionality or publishing market-related content.
- Never invent licences, approvals, partners, clients, trader counts, performance, capital or operating history.
- Do not add execution, copy trading, discretionary account management, deposits, withdrawals, custody or broker execution integrations to the first release.
- Keep proprietary trading separate from the independent trader network in language, data and permissions.
- Treat future services as planned until confirmed operational and appropriately authorised.
- Never commit secrets, keys, tokens or production personal data.
- Raise conflicts between implementation and documentation for product-owner decision.
